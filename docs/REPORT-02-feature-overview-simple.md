# RikkaHub Code 功能说明（简版）

> 面向使用者。这里只讲「有什么功能、能干什么、怎么用」，不涉及任何实现细节。

---

## 一句话

这是一个跑在安卓手机上的 AI 助手，能替你操作手机、上网、办公、跑脚本，还能在后台定时干活。

---

## 一、聊天

- 支持多家 AI 服务商，填个密钥就能用
- 可以建多个助手，每个助手有自己的性格、模型、工具、记忆和背景
- 回复可以重新生成、编辑、分支、复制
- 边说边发：正在回复时再发的消息会排队，不打断当前回答
- 语音输入，也可以让助手朗读回复
- 支持图片、文档、音频、压缩包等各种附件

## 二、操作手机

助手可以直接动手，包括：

- 点击、长按、滑动、输入文字、滚动页面
- 截图、读取当前屏幕上有哪些按钮和文字
- 打开应用、调亮度、调音量、发通知、震动、开手电筒
- 读电池、WiFi、信号、传感器、存储信息
- 读通讯录、通话记录、短信，也能发短信
- 拍照、录音、语音转文字、指纹验证
- 设置壁纸、读写 NFC 标签、管理压缩包

所有能力默认关闭，需要哪个开哪个，有副作用的操作每次都会问你。

## 三、内置浏览器

- 应用里自带一个完整浏览器，AI 可以自己打开网页、点按钮、填表单、往下滚
- 页面上方实时显示它每一步做了什么，做错了可以随时叫停
- 每一步截图都会传回聊天里，你能看到它在干什么
- 可以悬浮一个小聊天窗，不离开当前网页继续对话
- 网页上的请求、返回内容、控制台报错都能被记录下来，方便排查问题

## 四、上网找资料

- 内置搜索引擎，不用密钥就能用
- 还支持十几种搜索服务商，想用哪个填哪个的密钥
- 助手可以直接打开网页、提取正文，长文章会分段读，不会撑爆对话

## 五、Linux 工作区

手机上有一块完整的 Linux 环境：

- 可以跑命令、装软件、改文件
- 长任务能放后台跑（比如起个服务、跑个安装），随时查进度、随时停
- 自带文件管理器，能看图片、预览视频、直接打开网页和图形文件
- 可以从手机任何位置把文件导进来，也能把整个文件夹导出去

## 六、连自己的服务器

- 存一次服务器信息，之后随时连
- 跑命令、传文件、拉备份、看日志
- 起长期运行的服务也不会卡住

## 七、自动干活

**工作流**：说一句话就能建，比如「到家把铃声关掉」「连上车载蓝牙就打开导航」。支持十几种触发条件和十几种判断条件。

**定时任务**：想多久跑一次就多久跑一次，手机重启、省电模式下都不会漏。

## 八、子智能体

- 内置一百多个不同专长的角色（工程师、安全专家、设计师、测试……）
- 复杂的任务可以派给它们分头做，几个同时开工，最后汇总结果
- 可以指定便宜的小模型去干杂活，省钱
- 每个子智能体只能改你指定的目录，越界会被拦下

## 九、技能

一个文档就是一套新玩法。内置了一批现成的，比如：

- 二维码生成、维基查询、虚拟钢琴、交互地图
- 早间简报、通知摘要并自动处理、智能转发
- CTF 知识库、代码审计规则集

也可以自己写，或者从网上下载导入。

## 十、记忆与压缩

**记忆**：助手能长期记住你告诉它的事，跨会话不丢。

**压缩对话**：聊得太长会撑爆上下文，这个功能会自动把旧对话浓缩成摘要，让对话能一直继续。

压缩时会把**完整对话存档**，之后助手想不起来细节时，可以按关键词回查：

- 每次压缩存一份，第二次压缩只存新内容
- 回查时必须先问你要找哪一份，不会自作主张全翻一遍
- 只做关键词定位，不整篇读，避免又把上下文撑爆

**清理**：删掉对话或助手，对应的存档一起删。

## 十一、远程和自动化

- **Telegram 机器人**：在外面也能指挥家里的手机；能发图、发文件、发语音，审批用按钮点
- **通知转发**：指定应用的通知可以读、可以摘要、可以转发，点通知能直接跳回对应对话
- **外部调用**：其他自动化工具可以把任务丢给它

## 十二、本地模型

- 可以直接在手机上下载并运行小模型，不联网、不要密钥
- 部分机型支持系统自带的端侧模型
- 支持 AI 生图和改图

## 十三、Root 权限

手机有 root 的话，助手可以以最高权限执行操作：

- 能改系统设置、看其他应用的数据、动普通应用动不了的地方
- 默认关闭，打开后每次调用仍然要你批准
- 真正危险的操作（清空系统、刷机格式化这类）即使你说「永远允许」也会被拦下

## 十四、虚拟屏幕

在手机里**额外挂一块屏幕**，AI 可以把应用投上去、你能实时看到、也能自己点。

- **两种模式**：一块独立的空屏（只显示投进去的东西），或者镜像你当前手机的画面
- **投应用**：填个包名，应用就在这块屏上打开
- **实时画面**：设置页直接看到画面在动
- **全屏大窗**：专心操作时用，画面大，点一下、滑一下都能传给那块屏
- **悬浮小窗**：浮在别的应用上面，边刷手机边看着；顶部白条可拖动，点白条会出关闭按钮；点画面就是点那块屏
- **AI 也能操作**：截图看画面，按坐标点击、滑动
- **自动恢复**：退出去了再进来，虚拟屏和之前投的应用会自动回来
- **停止时清干净**：不会把你莫名其妙带到某个页面，小窗也会一起关掉

> 需要手机已 root。

## 十五、文件上传

现在什么文件都能传了，包括以前传不了的日志、压缩包、各种二进制文件。

- 能读的（文本、代码、配置）：内容直接给 AI 看
- 读不了的（压缩包、二进制）：自动放进 Linux 工作区，AI 可以用工具解压、打开
- 你只会看到文件本身，看不到那些给 AI 看的说明文字

## 十六、用量和信息显示

- 每条回复下面能看到：用了几步、多少 token、缓存命中多少、花了多少钱、生成速度、耗时
- 上下文占用了多少、还剩多少，一眼看清
- 点开还有详细面板

## 十七、调整思考深度

- 有的模型支持调整「思考深度」，从关闭到最高档
- 滑块拖动，形状和文字实时跟着变，松手才生效
- 档位越高，模型想得越久、答得越细

## 十八、上下文长度

- 编辑模型时可以直接选 128K / 200K / 1M，或者自己填
- 这个值会影响能聊多长，也影响用量面板里的占用比例

## 十九、聊天背景

- 可以设图片，也可以设**视频**
- 视频会静音循环播放，透明度跟着滑块走
- 离开聊天页自动停，回来继续，不浪费电

## 二十、健康检查

内置一个体检工具，一键检查：

- 权限有没有给全、后台服务在不在跑、数据库是否正常、网络通不通
- 各个依赖外部能力的工具（截图、启动应用、Termux、Shizuku、文件、浏览器）现在能不能用

发现问题可以一键修复，比如补授权、重启服务、重建索引。

## 二十一、其他

- 支持简体中文、繁体中文、英文、日文、韩文、俄文、阿拉伯文
- 有深色模式，多种主题配色
- 全界面支持读屏，视障用户也能操作

---

## 怎么开始

1. **设置 → 服务商**：选一家，填密钥（或者下个本地模型）
2. **设置 → 助手**：进你的助手，把需要的工具打开
3. 想用哪个功能，就开哪个开关；什么都不开，它就是一个普通聊天软件

## 安全说明

- 所有能力默认关闭，只开你要的
- 有副作用的操作每次都会先问你
- 真正危险的操作有硬性拦截，绕不过去
- 密码和密钥不会写进日志，备份也会跳过这些内容
- 远程机器人只认你的白名单

# 二十二、动手前的保险（安全层）

## 它会做什么

每次 AI 要动你的东西之前，先过一遍检查：

```
这是读还是写？
  读     → 直接跑，不打扰你
  写     → 看看能不能撤销
            能   → 弹个框告诉你「要改什么」，你点同意才动
            不能 → 看看是不是要命的东西
                    是 → 直接拒
                    不是 → 备份一份，再问你
```

## 备份

AI 要删或者覆盖一个文件之前，会先复制一份。

```
AI 要删 /workspace/笔记.txt
        ↓
先复制到 /workspace/.snapshots/时间戳/ 里
        ↓
再删
```

删错了能找回来。

**在哪看**：

```
设置 → 安全快照
```

里面列着每次备份：什么时候、哪个操作触发的、备份了几个文件、多大。

**也能直接用文件管理器看**：在「文件」页找 `.snapshots` 目录。

**普通写文件不会备份**，只有删除、擦除、覆写这种撤不回的才会。

## 拦不拦的规则

| 操作 | 会拦吗 |
|---|---|
| 看文件、查信息 | 不拦 |
| 在工作区里建文件改文件 | 不拦（会弹审批） |
| 删工作区里的文件 | 弹审批，同意后备份再删 |
| 删根目录、动系统文件 | 直接拒 |
| 通过软链接绕到系统目录 | 直接拒 |

# 二十三、先规划再动手

## 是什么

输入框那排图标里有个**地图**。点亮它，AI 就只出方案不动手。

```
点亮地图 → 说「帮我整理一下工作区」
        ↓
AI：先去看了你的目录，发现 23 个 md 文件散在 5 个文件夹里
    我打算这么做……
    ┌──────────────────────────┐
    │ 🗺 方案                    │
    │ ## 分组                    │
    │ 按主题分成三类              │
    │ ## 步骤                    │
    │ 1. 建三个文件夹            │
    │ ...                       │
    └──────────────────────────┘
```

看完觉得行，关掉地图，再说一遍，它才真动手。

**为什么有用**：让它直接干有时候会理解偏。先看方案再决定，省得改来改去。

**点地图之后输入框会变成「描述你的任务以生成计划」**——这时候发的不是聊天内容，
是让它出方案。

## 步骤条

正常模式下，如果 AI 把任务拆成了几步，输入框上方会出现一条：

```
2/5  整理工作区
● 扫目录  ● 分组  ○ 建文件夹  ○ 移动  ○ 验证
```

做完一步就填一个，全做完变全绿。

# 二十四、盯着一个目标干（目标）

## 和「计划」的区别

| | 计划 | 目标 |
|---|---|---|
| 管多久 | 这一轮 | 跨多少轮都行 |
| 干什么 | 这一轮分几步走 | 整体要达成什么 |
| 谁看 | 你 | 你和 AI |

## 怎么用

点**旗帜**，填一句话：

```
描述你的目标，定义可衡量的效果，以获得最佳效果
```

比如：

```
把工作区里所有 md 文件的标题改成一级标题格式，改完告诉我改了几个
```

填完点开始，旗帜变亮。

之后再点旗帜能看到进度：

```
状态      消耗          耗时
进行中    1234 tokens   2m30s
```

## 它会自己接着干

一轮回答完了，如果目标还没达成，它会自己再起一轮接着推——
不用你每次说「继续」。

**这个默认是关的**（在设置里），因为一直自动跑会烧钱。
开了之后最多自动续 5 轮，到上限自己停。

## 什么时候算完

AI 觉得做到了，会把目标标成「已完成」，面板上出现「结束目标」按钮。

点一下清掉，就能立新的了。

**目标做完了不用「放弃」**——那词是给半路不想干的情况用的。

# 二十五、技能：现在有 85 个

## 分好类了

```
内置      18   自带的（agent-core、ctf-kb、虚拟钢琴…）
工具链     3   装环境用的
逆向      17   APK、IDA、radare2、JS 逆向…
破甲       4   注册机、授权绕过
渗透      17   渗透工具、PWN、固件…
游戏安全  12   反作弊、内存、绘制
敏感       4   证件、资金、跨境
创作       3   成人向、叙事渲染
其他       7
```

**默认全部收起**，点分类名展开。不点就是九个标题，一眼看完。

## 都能看懂是干什么的

原来全是 `apk-reverse`、`seagull-pentest` 这种英文，现在每个都有中文名：

```
APK 逆向（反编译/改包/脱壳）
apk-reverse
在 CLI 环境下做 Android APK 逆向时使用……
```

## 找东西

顶部有搜索框，打中文打英文都能搜到。

## 自己加分类

点进任意技能 → 卡片下面「编辑名称与分类」：

```
中文名  [APK 逆向（反编译/改包/脱壳）]
分类    [我的逆向]
```

分类随便填，新的就是新分类。**填过就会记住**，下次别的技能也能选到它。

## 让 AI 自己写技能

```
助手 → 本地工具 → 让 AI 写技能
```

打开之后，你让它干完一件有难度的事，它会在末尾问一句：

> 要不要把这套流程存成一个技能？下次遇到同类目标能省不少时间。

你说要，它就自己写一个，还会问你：

- 叫什么
- 归到哪个分类（会先看你已有的分类）
- 描述写什么（这句话决定以后什么时候自动触发）

**写之前会弹审批**，你能看它写了什么再决定。

# 二十六、逆向工具链

## 装一次，一直在

跟 AI 说：

> 用 re-toolchain 技能，把逆向环境装好

它会跑一个脚本，装这些东西：

```
jadx        反编译 APK
apktool     拆包回编
smali       改字节码
radare2     命令行反汇编
frida       动态调试
pwntools    打 PWN
node        跑 JS 工具
java        跑 jar
```

**装在工作区里**（`/workspace/rev`），不是系统目录。这样工作区在，工具就在。

## 大概要多久

apt 那部分最慢，联网装 58 个包大概 5 分钟。全部装完 10 分钟左右。

## 装完能干什么

```
拆一个 APK 出来看代码
改完重新打包
签名装回手机
用 frida hook 它的验证
用 jadx-MCP 让 AI 直接查类和方法
```

## 出问题怎么办

技能里有一整张坑表，按「你看到的报错」反查。

最常见的三个：

```
apktool b 报 exit 132     → aapt2 架构不对，要装兼容层
下载的 jar 只有 9 字节     → URL 里的版本号写错了
pip 报 RECORD not found   → 缺 --ignore-installed
```

# 二十七、界面上的小改进

## 思考深度

原来是个光秃秃的灯泡，现在每个档位一张脸：

```
关闭    闭眼打呼噜，旁边飘三个 z
自动    圆点眼 + 微笑
低      半睁眼，迷迷糊糊
中      微笑，底下系着领带
高      微笑，头顶一个天使光环
超高    微笑，左右各一只天使翅膀 + 光环
最大    邪恶笑露尖牙，恶魔翅膀 + 头顶两只角
```

名字也改成实际参数了：`Off` / `Auto` / `Low` / `Medium` / `High` / `XHigh` / `Max`。

## 搜索按钮

开着搜索的时候，图标会变成：搜索方的 logo 放右下角，
左上角一个小放大镜，两者之间一道光束，logo 周围有一圈呼吸的光。

关掉就变回普通放大镜。

## 新建模型

上下文长度默认就是 1M，不用每次手动填。想改再改。

# 二十八、数据存哪

| 什么 | 存在哪 |
|---|---|
| 目标 | App 私有目录的 `agent-state/goals.json` |
| 计划 | 同上 `plans.json` |
| 操作记录 | 同上 `operation-audit.json` |
| 自建分类 | `skills/.categories.txt` |
| 文件快照 | **工作区里** `/workspace/.snapshots/` |
| 对话存档 | App 私有目录 `compaction/` |

**为什么用文件不用数据库**：数据量小，文件坏了删掉就能恢复，数据库坏了要修。

**目标是重启不丢的**——杀掉 App 再打开，进行中的目标还在。
