# 新功能测试清单

按最近几轮加的功能整理。每条都是「怎么操作 → 应该看到什么 → 看到别的说明什么」。

---

## 一、技能：分类、中文名、搜索、折叠

### 1.1 九个分类

```
助手 → 扩展 → 技能
```

**应该**看到九组，顺序固定：

```
内置 18 / 工具链 3 / 逆向 17 / 破甲 4 / 渗透 17 /
游戏安全 12 / 敏感 4 / 创作 3 / 其他 7
```

**默认全部收起**，每组标题左边有个 `›` 箭头。

### 1.2 折叠

点「逆向」那一行的标题。

**应该**：展开，箭头变 `⌄`。再点收起。

### 1.3 搜索

在顶部搜索框打「逆向」。

**应该**：分组自动展开，只显示匹配项。匹配范围包括中文名、英文标识符、描述。

打「apk」应该能搜到「APK 逆向（反编译/改包/脱壳）」。

### 1.4 全选

展开「破甲」，点标题右边的「全选」。

**应该**：4 个开关全亮，数字变 `4/4`，按钮变「全不选」。

**再点「全不选」**：全灭。

**这一条以前有 bug**——循环调 onToggle 每次都基于旧快照，只有最后一个生效。

### 1.5 默认不勾选

新建一个助手，打开技能页。

**应该**：85 个开关**全灭**。

如果 `autonomous-agent` 和 `openclaw-converter` 是亮的，说明那次清理没生效。

## 二、技能：自建分类 + 改中文名

### 2.1 改名字

```
技能列表 → 点任意技能 → 卡片底部「编辑名称与分类」
```

**应该**弹框，预填当前中文名和分类。

改成「测试技能」，分类填「我的测试」，保存。

**应该**：返回后顶部标题变了，卡片上的分类徽章变成「我的测试」。

### 2.2 新分类出现在列表

返回技能列表。

**应该**：多出「我的测试」分组。

### 2.3 分类会记住

把那个技能删掉，或者把它的分类改回去。

**再进任意技能的编辑框**，看「已有分类」的 chip。

**应该**：还能看到「我的测试」——它存在 `.categories.txt` 里，不依赖有没有技能用它。

## 三、技能：AI 自己写

### 3.1 开关默认关

```
助手 → 本地工具
```

**应该**：有一项「让 AI 写技能」，默认**不勾**。

### 3.2 开关关着时工具不存在

关着的时候，让 AI：

> 列出我所有的技能

**应该**：能列出来（`skill_list` 始终可用）。

让它：

> 帮我建一个技能

**应该**：建不了，会说没有这个工具。

### 3.3 打开开关

勾上「让 AI 写技能」，回到对话。

### 3.4 让它提议

干一件稍微复杂的事，比如：

> 帮我在沙箱里看看装了哪些工具，整理一下

它做完之后，**应该**在回复末尾问一句要不要存成技能。

**如果没问**：说明提示词没生效，或者 `skill_create` 没进工具表。

### 3.5 答应它

回「要」。

**应该**：它先调 `skill_list` 看已有分类，再调 `skill_create`。
弹出审批框（因为写工具要审批）。

批准后进技能列表，**应该**能看见新技能，默认不勾选。

## 四、技能：同名不覆盖

### 4.1 造两个同名技能

```
技能 → 加号 → 粘贴
```

第一份：

```
---
name: test-dup
description: 第一个
---
# 第一个技能
内容 A
```

保存。

再新建设一份，**name 也写 `test-dup`**。

**应该**：保存按钮是**灰的**，输入框变红。因为它检测到重名。

### 4.2 万一没灰

如果按钮还能点，点下去之后：

**应该**：弹提示「保存失败」，第一个技能**还在**。

**这一条以前有 bug**——列表刷新有延迟时能钻过去，直接覆盖。

## 五、计划模式

### 5.1 开关位置

```
聊天输入框那一排图标
```

**应该**是：鲸鱼头像 | 地图 | 旗帜 | 放大镜 | 灯泡 | 加号 | 发送

### 5.2 点亮地图

点地图，图标变亮。

### 5.3 让它写文件

地图亮着的时候：

> 在工作区建一个 test.txt，内容是 hello

**应该**：它说自己在计划模式，**没有写文件**，而是给一份方案。

**如果真写了**：只读闸门漏了。

### 5.4 方案卡片

上一步它输出的方案，**应该**渲染成带边框的卡片：

```
┌─────────────────────────────┐
│ 🗺 方案  在工作区创建 test.txt│
│                             │
│ ## Summary                  │
│ ...                         │
└─────────────────────────────┘
```

**不该**看到 `<proposed_plan>` 这串标签。

**如果标签裸露**：`AssistantTextBlock` 没生效。

### 5.5 步骤条

让它做一件多步的事，比如：

> 帮我看一下工作区结构，然后总结

它应该调 `update_plan`。**输入框上方**会出现一条：

```
1/3  读目录
● 读目录  ○ 分析  ○ 总结
```

## 六、目标

### 6.1 立目标

点旗帜 → 输入「把工作区里的 md 文件都整理一遍」→ 开始。

**应该**：旗帜变亮。

### 6.2 消耗和耗时

跑几轮之后，再点旗帜。

**应该**：

```
状态    消耗        耗时
进行中  1234 tokens  2m30s
```

**如果还是 `0 tokens` / `0s`**：`accumulateGoalTokens` 没跑起来。

### 6.3 完成后的按钮

让它把目标标成完成，或者你自己在面板里操作。

完成状态下**应该**：

- 只有「结束目标」一个按钮（主色）
- 下面一行说明「目标已达成。点「结束目标」把它从列表里清掉，再立新的。」
- **不该**有「放弃目标」

### 6.4 能立新目标

结束之后，再点旗帜，立一个新目标。

**应该**：能立。以前会被「已有未完成目标」拦住。

### 6.5 重启不丢

立一个目标，**杀掉 App**（从最近任务划掉），重新打开。

点旗帜。

**应该**：目标还在，状态还是「进行中」。

**如果没了**：JSON 落盘没生效。

## 七、安全层

### 7.1 只读命令不拦

沙箱里执行：

```sh
uname -a; cat /etc/os-release; pwd
```

**应该**：全部正常执行。

### 7.2 沙箱内写文件不拦

```sh
mkdir -p /workspace/logs /workspace/notes
touch /workspace/t.txt
```

**应该**：能写，或者弹审批（因为是写操作）。**不该**直接拒绝。

### 7.3 符号链接穿越要拦

```sh
ln -s /etc /workspace/etc-link
echo hacked > /workspace/etc-link/test.txt
```

**应该**：第二条被拒。因为 `/workspace/etc-link` 实际指向 `/etc`。

**如果放行了**：符号链接解析没生效。

### 7.4 危险操作还是要拦

```sh
rm -rf /
```

**应该**：被拒，提示不可恢复。

**这条必须拦。**

### 7.5 快照真的拍了

让 AI 做一个会改文件、且被判为不可逆的操作（比如 `shred` 一个工作区里的文件）。

审批通过后，检查：

```
文件管理器 → App 私有目录 → files/safety-snapshots/
```

**应该**：多一个以时间戳命名的目录，里面有 `manifest.json` 和 `files/`。

**如果目录是空的或者没有**：快照没拍。

### 7.6 审计落盘

同上操作之后，重启 App。

检查 `files/agent-state/operation-audit.json`。

**应该**：里面有记录，`argsDigest` 里的密码/token 都是 `[REDACTED]`。

## 八、MCP

### 8.1 一键配 jadx

```
设置 → MCP → 顶栏那个放大镜按钮
```

**应该**：弹出创建框，名字预填 `jadx`，URL 预填 `http://127.0.0.1:8123/mcp`。

### 8.2 只读工具免审批

如果你配了一个声明 `readOnlyHint: true` 的 MCP 服务器，
调它的工具**应该**不弹审批。

调一个没声明的，**应该**还是要审批。

## 九、工具链状态

跟 AI 说：

> 帮我看看沙箱里的逆向工具链装好了没

**应该**：它跑一条命令，然后报：

```
核心工具齐全（jadx / apktool / smali / node / java / r2）。
jadx-mcp 已下载（40MB）。
```

**如果缺 aapt2 兼容层**，会额外提示「arm64 上 apktool 回编会 SIGILL」。
