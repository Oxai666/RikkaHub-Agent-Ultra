# CTF 全方向知识库

本技能是**按需查阅的知识库**，不是一次性加载的长文。入口文件只提供导航；
具体技术细节分布在资源目录下的 13 个分类中，按需用 `read` 打开对应文件。

## 使用方式（重要：先定位再精读）

1. **先判断方向**：读题面 / 附件类型 / 目标地址，确定属于哪一类（web / pwn / re / crypto / misc …）。
2. **再读分类索引**：打开该分类的 `<分类名>.md`，它会列出该方向下的全部子技能清单。
3. **只精读命中的 1~3 个子技能文件**：每个子技能单独成文（如 `Web安全/SQL注入.md`）。
   **不要**一次性读取整个分类目录——总量很大，会挤爆上下文。
4. **按需交叉**：真实赛题常常跨方向（如 web 题里嵌 crypto、re 题里解 misc），
   命中后再打开相邻分类的对应文件。

## 与主流程的配合

- 涉及**具体站点的线上测试**（而非 CTF 赛题）时，应以用户交付的授权范围为准，
  并在动手前说明将要做的事；本知识库只提供技术要点，不构成授权。
- 需要**本地逆向工具**时，优先使用万象沙箱内置工具链（jadx / apktool / rg / python），
  而不是下载未知来源的二进制。
- 遇到**大文件**（流量包、固件、镜像）先用 `rg` 或 `binwalk` 等做结构感知，
  再用 `read(offset=, limit=)` 分片精读，禁止盲目全量读取。
